# CLI 登录规则修订

用户在拆分后明确要求：CLI 除上传 URL 外，其他上传都要登录。本修订覆盖原拆分方案中允许游客 HTML 上传的规则。

- `upload` 的 HTML、ZIP、目录和所有更新必须使用账号凭据。移除文件游客提交，拒绝 `upload --guest`，不触发上传网络写入。
- 新 URL 的 `link` 与 `link --mirror` 不要求登录。存在有效站点凭据或 GAMEHUB_TOKEN 时保留账号归属；没有凭据或本地凭据已过期时，使用现有匿名 URL 接口。
- `link --guest` 仅用于已登录时显式选择匿名。URL 更新仍需登录。
- 服务端拒绝账号凭据时直接报错，不自动以游客身份重复提交。
- `--dry-run` 是本地预检，继续免登录且不发起网络请求。文件预检没有游客模式。
- 描述与标签的自动准备规则保持不变；同步帮助、README 和 skill。
- 本次仅调整独立 CLI，不改变主站网页已有的游客上传能力或服务端接口。

验证：先新增认证策略回归测试，确认旧行为失败；修改实现后运行全套 CLI 测试和打包隔离验证。覆盖未登录文件、游客文件拒绝、无凭据 URL、镜像 URL、账号 URL、过期凭据、URL 更新和禁止授权失败后回退匿名。
